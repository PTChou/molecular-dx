FILE 01

案發現場

想像你為了好玩，把自己的 DNA 數據上傳到商業基因檢測網站。幾年後，警察敲門告訴你：他們靠你的基因數據，找到了你多年未見的遠親，一名連續殺人犯。

這不是科幻電影，而是 2018 年的「金州殺手案」。當科技走得比法律還快，我們的基因隱私該何去何從？

本課學習目標

  1. 掌握引導倫理討論的兩大核心技巧：角色代入與四角辯論。
  2. 探討公共利益與個人基因隱私之間的權衡與衝突。
  3. 學會用「論點攻防表」架構有說服力的思辨論點。

終身不變

密碼可以換，基因換不了。一旦外流，影響是一輩子。

牽涉家族

你與親屬共享一部分基因。嫌犯本人沒上傳，線索卻來自他的遠親。

預測未來

基因可能透露尚未發生的疾病風險，牽動保險、就業與婚姻。

兩個數字

FILE 02

偵訊技巧

技巧一：角色代入

不要直接問「你覺得怎麼樣？」，學生容易腦袋一片空白。改給一個具體身分，例如「如果你是保險公司的經理，你會怎麼決定？」

有了角色當盾牌，學生更能體會不同立場的難處，也更敢發言。

線上教學做法：用分組討論室，每組抽一個角色，5 分鐘後派代表以「我是○○，我認為……」開頭發言。

抽一個角色

按下按鈕，抽一個你要扮演的角色

技巧二：四角辯論

教室四角分別貼上「完全同意、部分同意、部分不同意、完全不同意」。丟出題目後，學生用身體站位表態並說明原因，聽完他人意見後可以隨時改站位。線上教學可請學生在聊天室輸入 1 到 4，或直接使用下面的線上版。

FILE 03

道德天秤

當「公共利益」或「他人的知情權」與「個人隱私」衝突，哪一方該優先？拖曳天秤，看看你的傾向落在哪裡。

警方在未經同意下，使用民眾主動上傳到商業家譜網站（如 GEDmatch）的 DNA 數據進行比對，成功逮捕消極避網數十年的連續殺人犯「金州殺手」。為了治安與抓捕重刑犯，警方有權使用這些並非授權給執法的數據嗎？今天為了抓罪犯妥協，明天這項科技會不會被用來監控政治異議者？

隱私方會說今天抓罪犯，明天就可能監控異議者；沒上傳的親戚也被牽連，資料庫還可能被駭。
公共利益方會說重大暴力案件的受害者也有權被看見；資料本來就是使用者自己公開上傳的。

討論問題

  1. 「主動上傳」算不算同意被警方使用？
  2. 如果只限殺人與性侵案，界線夠清楚嗎？
  3. 你沒上傳，但表哥上傳了，你的隱私還在嗎？
事件後，美國部分州（如馬里蘭州、蒙大拿州）陸續立法規範「法醫基因譜系」的使用條件。各州規定不同，請以最新資料為準。

你透過檢測，發現自己攜帶「阿茲海默症高風險」基因（例如 APOE ε4）。結婚前，你有義務主動告訴伴侶嗎？這究竟是誠實與對伴侶負責的表現，還是不容侵犯的個人隱私？

隱私方會說高風險不等於一定發病；被迫揭露，可能造成歧視與關係壓力。
知情權方會說婚姻牽涉長期照顧、財務與生育決定，伴侶有權在知情下做選擇。

討論問題

  1. 「風險」與「確定會發生」，在告知義務上有差別嗎？
  2. 如果你是遺傳諮詢師，你會建議怎麼說？
  3. 這份資訊也影響兄弟姊妹與子女，他們有知情權嗎？
APOE ε4 帶來的是較高的機率，並非診斷。解讀基因風險需要專業諮詢。

攻防推理

辯論中只說「我覺得」是不夠的。論點攻防表用四個格子，把立場、對手的反擊、證據與回應放在同一頁。下方已填入範例，可以直接改寫成你的版本。

自我檢查：論點能用一句話說完嗎？② 是對手最強的反擊，而不是最弱的嗎？③ 的證據能被查證嗎？④ 是在回應 ②，還是只在重複 ①？

引導技巧

「角色代入」降低發言門檻，「四角辯論」讓抽象觀點看得見，兩者都能活化課堂討論。

倫理衝突

基因隱私不只是個人私事。在公共安全與親密關係中，都牽涉公共利益、知情權與隱私權的拉扯。

思辨能力

高品質的辯論要有論點、預測反擊、證據與反駁，缺一不可。

科技的發展永無止境。如何在享受便利的同時，守住人權與隱私的底線，是每個人都要持續思考的課題。

時間活動做法
0–5'開場故事講述金州殺手案，問：「你上傳過任何生物資料嗎？」
5–12'四角辯論三個表態題，每題請兩位說明理由，允許改站位。
12–27'角色代入分組抽角色，討論情境 A 或 B，每組派代表發言。
27–38'論點攻防表個人填寫後與鄰座交換，讓對方扮演「對手」提出攻擊。
38–45'總結與反思請學生寫下「我最初的立場」與「我現在的立場」。

人數少於 12 人時，可省略分組。線上授課可把四角辯論改成聊天室輸入 1 到 4。
